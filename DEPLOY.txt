DSH 新电脑部署指南（办公室/家用通用）
========================================
适用：在一台全新 Windows 电脑上部署与你现有电脑完全一致的 DSH 环境。
全程约 15~25 分钟（含下载依赖和构建）。请按顺序执行。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 0 步：安装基础工具（约 5 分钟）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1) Node.js LTS (v22 或更高)
   下载: https://nodejs.org → LTS 版 → 默认选项安装
2) git for Windows
   下载: https://git-scm.com/download/win → 默认选项安装
   (自带 Git Credential Manager, 首次连 GitHub 会弹浏览器授权)
3) pnpm
   开始菜单搜 "PowerShell" 打开, 执行:
       npm install -g pnpm
4) 验证 (新开一个 PowerShell 窗口执行, 三个都有版本号即合格):
       node --version
       pnpm --version
       git --version
   注意: 必须【新开】窗口, 刚装完的软件在旧窗口里找不到。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 1 步：开启 VPN 并克隆本配置仓库
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1) 开启 vpn07 (确认系统代理已启用)
   查看代理端口: 设置 → 网络和 Internet → 代理 → 手动设置代理,
   记下地址, 一般为 127.0.0.1:7688
2) PowerShell 执行 (端口不同请替换 7688):
       git -c http.proxy=http://127.0.0.1:7688 -c https.proxy=http://127.0.0.1:7688 clone https://github.com/liaojiawei0428/dsh-ops.git D:\GongJu\DSH-ops
   首次会弹浏览器 → 登录 GitHub → 点授权, 之后凭据自动缓存。
   克隆失败(连接重置/超时) = VPN 没生效, 检查代理端口后重试。

   【重要】目录必须是 D:\GongJu\DSH-ops, 不能换盘符或改名
   (插件以绝对路径链接, 换路径会导致安装脚本失败)。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 2 步：拷贝 API 凭据（一次性, 用 U 盘）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
从已部署的电脑拷贝:
       C:\Users\<旧电脑用户名>\.dsh\.credentials.yaml
到本电脑同位置:
       C:\Users\<本机用户名>\.dsh\.credentials.yaml
(.dsh 文件夹不存在就手动创建)

【安全提醒】该文件含 API Key 明文:
   - 只用 U 盘/局域网私有渠道传输
   - 不要上传网盘、不要发聊天工具、不要发邮件
   - 忘了拷也不影响安装, 装完后在 DSH 网页设置里重新填 Key 即可

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 3 步：双击安装（约 10~20 分钟）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
双击 D:\GongJu\DSH-ops\安装DSH.bat

脚本自动完成:
   [0/7] 检查 node/pnpm/git
   [1/7] 检查系统代理 (VPN)
   [2/7] 克隆官方 DSH 源码到 D:\GongJu\Deepseek_DSH + 写入国内 npm 镜像
   [3/7] pnpm install (下载依赖, 最耗时的一步)
   [4/7] pnpm run build (构建)
   [5/7] 注册自定义插件 dsh-locale-language (界面语言跟随)
   [6/7] 应用用户配置 settings.yaml (模型/主题)
   [7/7] 创建桌面快捷方式「DSH 启动」

窗口显示绿色的 "安装完成!" 即成功。
中途报错会停下并显示原因, 按 README 排查或截图反馈。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 4 步：验证清单（逐项确认）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
□ 桌面出现「DSH 启动」快捷方式
□ 双击它 → 自动弹出 http://127.0.0.1:3080 页面
□ 页面能正常发消息、模型能回复 (说明凭据生效)
□ 用中文提问, 模型用中文思考和回复 (说明 locale 插件生效)
□ 模型下拉里有 glm-5.3 等自定义模型 (说明 settings 生效)
□ PowerShell 里执行 git -C D:\GongJu\DSH-ops pull
  显示 "Already up to date" (说明同步通道正常)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
故障排查
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
| 现象 | 原因 | 处理 |
|------|------|------|
| 克隆 dsh-ops 失败/超时 | VPN 未生效 | 确认 vpn07 运行且系统代理启用, 核对端口号 |
| 安装时 GitHub 克隆失败 | 同上 | 同上 (脚本会在代理诊断处黄字提示) |
| pnpm install 卡住不动 | npm 镜像未生效 | 检查 D:\GongJu\Deepseek_DSH\.npmrc 是否存在 |
| 构建失败 | 极少见, 多为内存不足 | 关掉大型程序重跑安装DSH.bat (可重复执行, 幂等) |
| 页面打不开 | 服务未起 | 看 D:\GongJu\DSH-ops\dsh-web.err.log |
| 模型报 401/无效 Key | 凭据未拷或失效 | 检查第 2 步, 或网页设置里重新填 |
| 模型回复是英文 | 插件未注册 | 重跑安装DSH.bat 看第 5 步是否报错 |

部署完成后的日常使用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
启动:  双击桌面「DSH 启动」(自动检查更新 + 打开页面)
升级:  双击 D:\GongJu\DSH-ops\更新DSH.bat
同步:  改了配置后 git push, 这台电脑 git pull
停止:  Stop-Process -Id (Get-Content D:\GongJu\DSH-ops\dsh-web.pid) -Force
详见:  D:\GongJu\DSH-ops\README.txt
