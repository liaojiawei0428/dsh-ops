用户反馈精炼室选中向日葵后只见"暂无精炼需求，请稍后重试"兜底文案且无报错弹窗。排查：游戏服直连 curl tu_jian_refine_plan 返回 ok:true 与完整清单（7 种材料+精华），说明服务端功能正常；随后核对后台代理层 logic.service.ts runOnce（L446-491）——其返回结构为 {ok, code, messageZh, raw, changes}，游戏服完整响应放入 raw 字段，返回对象本身没有 data 键；logic.controller.ts @Post('run') 原样 return。而前端 fetchRefinePlan 读取 res.data（类型上也不存在，LogicRunResult 只有 raw），恒得 undefined，但 res.ok=true 所以既不报错也不显示清单，refinePlan 置 null 后模板落入"暂无精炼需求"分支。修复：index.vue fetchRefinePlan 改为读 res.raw.data 并优先取 raw 的 messageZh/code；重新 npm run build 通过，dist 54 文件全量上传线上（nginx 静态目录）。doQuick 等既有调用只读 ok/messageZh/code 不受影响。
