需求背景：用户要求把世界网格的「摆放物信息」显示在**网格地图右侧**以节省垂直空间（前一轮已交付两栏布局）。本轮用户反馈：「现在是靠近网页右边栏，我需要的是在网格地图右侧，不是网页右侧」——即面板横向位置错误，贴在内容区最右边缘，与网格之间出现大片空白。

排查：读取模板与样式确认结构——工具栏 `.grid-toolbar` 在容器外层全宽；`.grid-layout`（flex + wrap + align-items:flex-start）内为 `.grid-main`（含 `.world-grid`）与 `.grid-side`（aside）。网格本体宽度固定：`:style="{gridTemplateColumns:'repeat(gridShownW, gridCellPx px)'}"`，即 50×15px=750px 列宽 + 49×1px gap + 2px border ≈ 801px。

根因：`.grid-main{flex:1 1 520px}` —— 虽然 flex-basis 是 520px，但 flex-grow:1 让它吞掉容器全部剩余宽度；网格只有约 801px，多出来的空间全被算进左栏宽度，于是紧随其后的 280px 面板被推到容器末端（视觉上的「网页右边栏」）。这是「左栏内容固定宽度 + 左栏 flex-grow:1」的经典错配。

修复：`.grid-main{flex:0 1 auto; min-width:0; max-width:100%; overflow:auto}` —— 不放大（宽度=网格自然宽度）、仍可收缩（空间不足时网格自身横向滚动而面板位置不变）、防溢出。`.grid-side{flex:0 0 280px;width:280px}` 不变。因 min-width:0 使左栏 min-content 为 0，flex-wrap 实际不会触发换行，面板在任意宽度下都恒在网格右侧。

验证：`npm run build` exit 0（vue-tsc + vite 6.91s）→ deploy_dist_local.py 上传 54 文件（旧包备份 /tmp/dist-backup-20260916-103910.tgz）→ 线上 `assets/index-D_Zrq_IH.css` 确认新规则 `.grid-main[data-v-a1381e60]{flex:0 1 auto;min-width:0;max-width:100%;overflow:auto}` 与 `.grid-side[data-v-a1381e60]{flex:0 0 280px;width:280px;…}` → https://yx.maque.uno/ 200。

教训：两栏布局中若左栏内容是固定宽度（网格/画布/固定列列表），左栏禁用 flex-grow:1；只有内容需要填充自适应（文本流、表格）时才用 flex:1 1 <basis>。
